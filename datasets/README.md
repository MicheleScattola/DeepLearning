# Datasets available:
- `pi_LH.npy`, `pi_RH.npy`, `rho_LH.npy` and `rho_RH.npy` contain events with only LH or RH decays.
- `pi.npy` , `rho.npy` contain events from a random mixture created to resemble the Standard Model tau polarization of $P \sim -0.147$

The columns of the datasets are in order:
- $x_{vis} = E_{track}/E_\tau$ 
- $E_{cone}$ 
- $f_{had}$
- $\eta_{track}$
